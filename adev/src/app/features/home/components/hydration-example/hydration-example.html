即時水合

重要元件（如導覽或首屏內容）會在主應用程式套件就緒後立即水合。

漸進水合

使用 on interaction 或 on timer 等水合觸發條件， 延後非關鍵元素的 JS 執行。

事件重播

使用者的點擊永遠不會遺失。Angular 會在「靜態」階段記錄事件， 並在水合完成後重新派送它們。
