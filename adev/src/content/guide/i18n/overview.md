# Angular 國際化

*國際化*，有時被稱為 i18n，是針對世界各地不同地區的使用者設計和準備專案的過程。
*在地化*是為不同地區建立專案版本的過程。
在地化過程包括以下動作。

* 提取文字以翻譯成不同的語言
* 格式化特定地區設定的資料

*locale* 可識別人們講特定語言或語言變體的地區。
可能的區域包括國家和地理區域。
地區語言設定決定以下詳細資料的格式化和剖析。

* 包含日期和時間、數字和貨幣的測量單位
* 包括時區、語言和國家的翻譯名稱
