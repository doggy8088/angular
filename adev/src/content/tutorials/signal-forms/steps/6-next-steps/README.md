## 你學到了什麼

在本教學中，你學到了 Angular Signal Forms 的基礎：

1. **表單模型**：使用訊號與 `form()` 函式建立具型別安全的表單資料
2. **欄位繫結**：使用 `[formField]` 指令進行雙向資料繫結，並以 `value()` 顯示欄位
3. **驗證**：套用內建驗證器（例如 `required()`、`email()`）並搭配自訂訊息
4. **錯誤顯示**：依欄位狀態條件式顯示驗證錯誤
5. **表單提交**：使用 `submit()` 函式處理表單提交
