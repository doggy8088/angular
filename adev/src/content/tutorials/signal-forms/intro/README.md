# 學習 Angular 訊號表單

這份互動教學將帶你學習如何使用 Angular 實驗性的訊號表單 API，建立反應式表單。

IMPORTANT: Signal Forms 目前仍屬[實驗性](reference/releases#experimental)功能。API 在穩定下來之前可能會有所變更。請查看[官方文件](guide/forms/signals/overview)，了解最新動態。

## 如何使用這份教學

這份教學假設你已理解 Angular 的核心概念，並且對訊號有基本的認識。如果你是 Angular 新手，請先閱讀我們的[精華指南](/essentials)。如果你剛接觸訊號，請先完成[訊號教學](/tutorials/signals)。

每個步驟都代表訊號表單的一個概念。你將從零開始建立一個完整的登入表單，一步步學習基本原理。

**你的學習路徑**：

1. 使用 TypeScript 與訊號建立表單模型
2. 將表單連接到你的範本
3. 加入驗證規則
4. 向使用者顯示驗證錯誤
5. 處理表單提交
6. 探索進階主題與後續學習方向

如果卡住了，點選上方的 "Reveal answer" 即可查看答案。
