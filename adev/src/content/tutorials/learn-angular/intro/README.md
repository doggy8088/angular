# 歡迎使用 Angular 教學

這個互動式教學課程將會教你開始使用 Angular 建立優秀應用程式的基本架構。

您也可以在我們的 [指南](overview) 和 [參考](api) 中了解更多資訊，或 `ng new`。

## 如何使用本教學

您需要具備 HTML、CSS 和 JavaScript 的基本知識，才能了解 Angular。

每個步驟都代表 Angular 中的一個概念。您可以執行其中一個，或所有步驟。

如果您受困，請按一下頂端的「顯示答案」。
