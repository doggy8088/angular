# Bootstrapped NgModule 不指定要初始化的組件

此錯誤表示用於引導應用程式的 NgModule 缺少 Angular 繼續引導程序的關鍵資訊。

當 `@NgModule` 註解中缺少 NgModule `bootstrap` 屬性（或為空陣列），且該 NgModule 類別上未定義 `ngDoBootstrap` 生命周期掛鉤時，就會發生錯誤。

有關引導程序的更多資訊，請參閱 [此指南](guide/ngmodules/bootstrapping)。

以下範例會觸發錯誤。

```typescript
@NgModule({
  declarations: [AppComponent],
  imports: [BrowserModule, AppRoutingModule],
  providers: [],
})
export class AppModule {}

// The `AppModule` is used for bootstrapping, but the `@NgModule.bootstrap` field is missing.
platformBrowser().bootstrapModule(AppModule);
```

```typescript
@NgModule({
  declarations: [AppComponent],
  imports: [BrowserModule, AppRoutingModule],
  providers: [],
  bootstrap: [],
})
export class AppModule {}

// The `AppModule` is used for bootstrapping, but the `@NgModule.bootstrap` field contains an empty array.
platformBrowser().bootstrapModule(AppModule);
```

## 偵錯錯誤

請確定用於引導的 NgModule 已正確設定：

- `@NgModule` 註解中存在 `bootstrap` 屬性（並包含非空陣列）
- 或 NgModule 類別中存在 `ngDoBootstrap` 方法
