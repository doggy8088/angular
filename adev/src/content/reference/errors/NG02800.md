# HttpClient 配置中的 JSONP 支援

當您嘗試在 `HttpClient` 組態中未提供必要的 `JSONP` 請求支援時，Angular 會產生此錯誤。
若要啟用 `JSONP` 支援，您可以執行下列其中一項操作：

- 在使用 `bootstrapApplication` 時，在 `provideHttpClient` 函式呼叫期間新增 `withJsonpSupport()` 作為引數（例如 `provideHttpClient(withJsonpSupport())`）
- 在使用基於 NgModule 的引導程式時，在根 AppModule 中匯入 `HttpClientJsonpModule`。## 除錯錯誤
請務必將 JSONP 支援新增到應用程式中，方法是呼叫 `withJsonpSupport` 函式（在使用 `provideHttpClient` 時）或匯入 `HttpClientJsonpModule` 模組，如上所述。
