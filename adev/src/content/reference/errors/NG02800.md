# HttpClient 設定中的 JSONP 支援

當你嘗試發出 `JSONP` 請求，卻沒有在 `HttpClient` 設定中提供必要的支援時，Angular 就會產生這個錯誤。若要啟用 `JSONP` 支援，你可以採取下列其中一種做法：

- 使用 `bootstrapApplication` 時，在呼叫 `provideHttpClient` 函式時把 `withJsonpSupport()` 作為引數傳入（例如 `provideHttpClient(withJsonpSupport())`）
- 使用以 NgModule 為基礎的啟動方式時，在根 AppModule 中匯入 `HttpClientJsonpModule`。## 如何除錯
請確認你已依上述方式為應用程式加入 JSONP 支援：呼叫 `withJsonpSupport` 函式（使用 `provideHttpClient` 時），或匯入 `HttpClientJsonpModule` 模組。
