# 參數非文字

為了讓 Angular 編譯器中的元數據萃取速度更快，以下裝飾器 `@NgModule`、 `@Pipe`、`@Component`、`@Directive` 和 `@Injectable` 只接受物件字面量作為參數。

這是一個 [Ivy 中的故意變更](https://github.com/angular/angular/issues/30840#issuecomment-498869540)，它對裝飾器的參數要求比 View Engine 更嚴格。
Ivy 採用這種方法是因為它會編譯裝飾器，將表達式移至類別輸出中的其他位置。

## 偵錯錯誤

移動所有宣告：

<docs-code language="typescript">

const moduleDefinition = {&hellip;}

@NgModule(moduleDefinition)
export class AppModule {
    constructor() {}
}

</docs-code>

into the decorator:

<docs-code language="typescript">

@NgModule({&hellip;})
export class AppModule {
    constructor() {}
}

</docs-code>
