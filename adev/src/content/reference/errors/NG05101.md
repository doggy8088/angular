# 找不到事件的事件管理員外掛程式

當 Angular 嘗試為某個事件設定監聽器，但沒有任何已註冊的事件管理員外掛程式能辨識該事件名稱時，就會發生此錯誤。

## 除錯方式

錯誤訊息中包含無法辨識的事件名稱。此錯誤只會在沒有任何已註冊外掛程式支援該事件時發生，例如以不包含 `DomEventsPlugin` 的自訂外掛程式清單建立 `EventManager` 時，常見於單元測試或自訂設定中。

如果該事件名稱是刻意使用的，且屬於第三方外掛程式（例如 Hammer.js 手勢事件），請確保該外掛程式透過 `EVENT_MANAGER_PLUGINS` 權杖提供：

```typescript
import {ApplicationConfig} from '@angular/core';
import {EVENT_MANAGER_PLUGINS} from '@angular/platform-browser';

export const appConfig: ApplicationConfig = {
  providers: [{provide: EVENT_MANAGER_PLUGINS, useClass: MyCustomPlugin, multi: true}],
};
```
