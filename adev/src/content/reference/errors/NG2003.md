# 遺失 Token

編譯時沒有建構函數參數的注入代幣。[InjectionTokens](api/core/InjectionToken) 是可用於相依性注入提供者的代幣。

## 偵錯錯誤

看看拋出錯誤的參數，以及類的所有使用情況。
當建構函數定義了具有基本類型（例如 `string`、`number`、`boolean` 和 `Object`）的參數時，通常會拋出此錯誤。

使用 `@angular/core` 中的 `@Injectable` 方法或 `@Inject` 裝飾器，以確保您注入的類型被具體化 \(具有執行時期表示\)。務必為此裝飾器新增提供者，以避免拋出 [NG0201: 未找到提供者](errors/NG0201)。
