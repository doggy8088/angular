# 無效屬性

<docs-video src="https://www.youtube.com/embed/wfLkB3RsSJM"/>

屬性或特徵無法在編譯期間解析。

此錯誤在嘗試繫結至不存在的屬性時發生。
任何屬性繫結都必須對應至：

* HTML 元素上的原生屬性，或
* 應用於該元素的元件或指令的 `@Input()` 屬性。

這個的執行時期錯誤是 `NG0304: '${tagName}' 不是已知的元素: &hellip;'`。

## 偵錯錯誤

請參閱特定 [binding syntax](guide/templates) 使用的文件。這通常是錯字或不正確的匯入。
可能還有缺少具備屬性選擇器「名稱」的方向或缺少輸入。
