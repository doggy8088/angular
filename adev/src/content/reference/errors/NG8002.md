# 無效的屬性

<docs-video src="https://www.youtube.com/embed/wfLkB3RsSJM"/>

在編譯期間，某個特性或屬性無法解析。

當嘗試繫結到不存在的屬性時，就會發生此錯誤。
任何屬性繫結都必須對應到以下其中之一：

- HTML 元素上的原生屬性的，或
- 套用到該元素之元件或指令的 `input()`/`@Input()` 屬性。

此錯誤的執行時期版本是 `NG0303: Can't bind to '${propName}' since it isn't a known property of '${tagName}'`。

## 除錯方式

請查閱所用特定[繫結語法](guide/templates)的文件。這通常是錯字或不正確的匯入。
也可能有方向缺失與屬性選擇器 'name'，或缺少輸入。
