# `inject()` 必須從注入內容中呼叫

當您嘗試在允許的 [注入](api/core/inject) 語境以外使用 [`inject`](api/core/inject) 函式時，您會看到此錯誤。注入語境在類別建立和初始化期間可用。對於與 `runInInjectionContext` 一起使用的函式，它也可用。

在實務上，`inject()` 呼叫允許在建構函式、建構函式參數和欄位初始化程式中：

```typescript
@Injectable({providedIn: 'root'})
export class Car {
  radio: Radio|undefined;

  // OK: field initializer
  spareTyre = inject(Tyre);

  constructor() {
    // OK: constructor body
    this.radio = inject(Radio);
  }
}
```

也可以從提供者的工廠呼叫 [`inject`](api/core/inject)：

```typescript
providers: [
  {provide: Car, useFactory: () => {
    // OK: a class factory
    const engine = inject(Engine);
    return new Car(engine);
  }}
]
```

在類別建立或 `runInInjectionContext` 之外的呼叫 [`inject`](api/core/inject) 功能將導致錯誤。最值得注意的是，在建立類別實例之後、在方法（包含生命週期掛鉤）中不允許呼叫 `inject()`：

```typescript
@Component({ ... })
export class CarComponent {
  ngOnInit() {
    // ERROR: too late, the component instance was already created
    const engine = inject(Engine);
    engine.start();
  }
}
```

## 偵錯錯誤

從錯誤的堆疊追蹤反向工作以識別位於禁止呼叫 `inject()` 的位置。

若要修正錯誤，請將 [`inject`](api/core/inject) 呼叫移至允許的位置 (通常是類別建構函式或欄位初始化函式)。

**注意：**如果您在測試情境中執行，`TestBed.runInInjectionContext` 將啟用 `inject()` 以成功執行。

```typescript
TestBed.runInInjectionContext(() => {
   // ...
});
```
