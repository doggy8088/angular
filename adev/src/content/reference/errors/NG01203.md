# 遺失的值存取器

對於所有自訂表單控制，您必須註冊一個值訪問器。

以下是如何提供範例：

```typescript
providers: [
  {
    provide: NG_VALUE_ACCESSOR,
    useExisting: forwardRef(() => MyInputField),
    multi: true,
  }
]
```

## 偵錯錯誤

如上所述，預期你的控制項會有一個值存取器，但卻找不到一個。然而，在實際情況下，可能有很多不同的原因導致這種情況。以下列出一些導致此錯誤的已知問題。

1. 如果你**定義**了自訂表單控制項，你是否記得提供值訪問器？
1. 你是否將 `ngModel` 放置在沒有值的元素或**無效元素**上（例如 `<div [(ngModel)]="foo">`）？
1. 你是否在 `NgModule` 內部使用宣告的自訂表單控制項？如果是，請確定你**匯入**了 `NgModule`。
1. 你是否將 `ngModel` 與第三方自訂表單控制項一起使用？請檢查該控制項是否提供值訪問器。如果不是，請在控制項的元素上使用**`ngDefaultControl`**。
1. 你是否**測試**自訂表單控制項？請務必將測試平台設定為了解該控制項。你可以使用 `Testbed.configureTestingModule` 來做到這一點。
1. 你是否在 Webpack 中使用**Nx 和模組聯合**？你的 `webpack.config.js` 可能需要[額外設定](https://github.com/angular/angular/issues/43821#issuecomment-1054845431)以確保表單套件是共用的。
