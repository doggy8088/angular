# NgZone 持續不穩定

當用戶端已啟用水合、但 NgZone 長時間持續不穩定時，就會出現此警告。

`ApplicationRef.isStable()` API 會利用 NgZone 回報應用程式何時變為 `stable` 與 `unstable`。當沒有待處理的微任務或巨集任務時，應用程式即被視為穩定。

Angular 水合仰賴 Zone.js 在應用程式內變得穩定時發出的訊號：

* 在伺服器端渲染（SSR）期間，用來開始序列化程序
* 在瀏覽器中，此訊號用來開始水合後的清理，移除未被認領而殘留的 DOM 節點

當 `ApplicationRef.isStable()` 在 10 秒內沒有發出 `true` 時，就會顯示此警告。如果這是刻意為之，且你的應用程式稍後會變得穩定，你可以忽略此警告。

## 巨集任務

巨集任務包括 `setInterval`、`setTimeout`、`requestAnimationFrame` 等函式。
如果在應用程式的初始化階段或啟動的元件中呼叫了其中任何一個函式，應用程式將持續不穩定。

```typescript
@Component({
  standalone: true,
  selector: 'app',
  template: ``,
})
class SimpleComponent {
    constructor() {
        setInterval(() => { ... }, 1000)

        // or 

        setTimeout(() => { ... }, 10_000)
    }
}
```

如果必須在初始化階段呼叫這些函式，在 Angular 區域之外呼叫它們即可解決問題。  

```typescript
class SimpleComponent {
    constructor() {
      inject(NgZone).runOutsideAngular(() => {
        setInterval(() => {}, 1000);
      })
    }
}
```

## 如何除錯

請確認你沒有任何長時間存在的微任務或巨集任務。
