# NgZone 仍然不穩定

當在客戶端啟用水合作用，但 NgZone 在長時間內仍不穩定，就會發生此警告。

`ApplicationRef.isStable()` API 使用 NgZone 來報告應用程式何時變為「穩定」和「不穩定」。當沒有待處理的微任務或巨集任務時，應用程式即被視為穩定。

Angular Hydration 依賴來自 Zone.js 的信號，當它在應用程式內部變得穩定時：

* 在伺服器端渲染 (SSR) 期間啟動序列化程序
* 在瀏覽器中，此信號用於啟動後水合清理，以移除未宣告的 DOM 節點

當 `ApplicationRef.isStable()` 未在 10 秒內發出 `true` 時，會顯示此警告。如果這是故意的，而您的應用程式稍後變得穩定，您可以忽略此警告。

## Macrotasks

html
<div id="demo">
  <p>Click the button to display the date.</p>
  <button type="button" onclick="displayDate()">Display the Date</button>
</div>

<script>
function displayDate() {
  document.getElementById("demo").innerHTML = Date();
}
</script>

巨觀任務包含像 `setInterval`、`setTimeout`、`requestAnimationFrame` 等函數。
如果在應用程式的初始化階段或引導組件中呼叫了這些函數中的其中一個，那麼應用程式將會保持不穩定。

```typescript
@Component({
  standalone: true,
  selector: 'app',
  template: ``,
})
class SimpleComponent {
    constructor() {
        setInterval(() => { ... }, 1000)

        // or 

        setTimeout(() => { ... }, 10_000)
    }
}
```

如果這些函數需要在初始化階段被呼叫，在 Angular 區域外呼叫它們可以解決該問題。

```typescript
class SimpleComponent {
    constructor() {
      inject(NgZone).runOutsideAngular(() => {
        setInterval(() => {}, 1000);
      })
    }
}
```

## 偵錯錯誤

驗證您沒有任何長久存在的微任務或巨集任務。
