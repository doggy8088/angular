# 無效的元素

在編譯期間有一或多個元素無法解析，因為該元素未在 HTML 規範中定義，或沒有具有該元素選擇器的元件或指令。

HELPFUL: 這是常見執行時期錯誤 `NG0304: '${tagName}' is not a known element: ...` 的編譯器對應版本。

## 除錯方式

使用錯誤中的元素名稱，找出使用該元素的檔案。

檢查名稱與選擇器是否正確。

檢查元件在 `imports` 欄位中是否存在，確認該元件已正確匯入你的 NgModule 或獨立元件中。如果該元件宣告在 NgModule 中（表示它不是獨立元件），請檢查它在 `exports` 欄位中是否存在，確認它已正確從該模組匯出。

使用自訂元素或 Web 元件時，請確保你已把 [`CUSTOM_ELEMENTS_SCHEMA`](api/core/CUSTOM_ELEMENTS_SCHEMA) 加入應用程式模組。

如果這樣仍無法解決錯誤，請檢查匯入的程式庫中你所使用的匯出與屬性是否有近期變更，並重新啟動你的伺服器。
