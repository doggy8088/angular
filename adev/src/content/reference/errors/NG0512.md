# 水合缺少文字

這個錯誤與[錯誤 NG0500](errors/NG0500) 類似，但它的意思是 Angular 的水合程序預期在 DOM 的特定位置找到一個文字節點，卻什麼也沒找到。關於直接操作 DOM 相關的原因，請查看[錯誤 NG0500](errors/NG0500) 頁面。

## 常見原因：伺服器 HTML 在水合之前被改動

水合會重複使用伺服器端渲染產生的文字節點。如果在瀏覽器執行應用程式之前，有東西移除或合併了這些文字節點，Angular 要找的節點就不見了。

常見的來源包括 HTML 壓縮器、改寫回應的代理伺服器或 CDN、瀏覽器擴充功能，或是在 Angular 之外以 `innerHTML` 寫入文字的應用程式程式碼。

## 除錯方式

關於直接操作 DOM 相關原因的除錯技巧，請參閱[錯誤 NG0500](errors/NG0500)。

比較伺服器送出的 HTML 與瀏覽器收到的 HTML。請使用頁面原始碼，而非元素檢查器，因為檢查器顯示的是水合已經執行過的 DOM。如果文字出現在伺服器回應中，但在瀏覽器中卻遺失了，請找出中間改寫 HTML 的工具。

如果你無法控制某個元件的 HTML，可以在它的宿主節點上加入 `ngSkipHydration` 屬性，作為最後的手段。這會停用該元件及其子元件的水合，應該被視為一個需要修復的錯誤。
