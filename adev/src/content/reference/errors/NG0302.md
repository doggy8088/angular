# 找不到管道

<docs-video src="https://www.youtube.com/embed/maI2u6Sxk9M"/>

Angular 找不到這個名稱的管道。

範本中參考的[管道](guide/templates/pipes)尚未被正確命名或宣告。

要使用這個管道：

- 確保範本中使用的名稱，與管道裝飾器中定義的名稱相符。
- 把管道加入你的元件 `imports` 陣列；或者，如果該管道設定了 `standalone: false`，請把該管道所屬的 `NgModule` 加進來。

## 如何除錯

使用管道名稱，追蹤它是在哪裡宣告與使用的。

要解決這個錯誤：

- 如果該管道是某個 `NgModule` 的本地管道，請在管道的裝飾器中為它取一個唯一的名稱，並把它宣告在該 `NgModule` 中。
- 如果該管道是獨立管道，或宣告在另一個 `NgModule` 中，請把它加入獨立元件或目前 `NgModule` 的 `imports` 欄位。

如果你最近才加入新的匯入或宣告，可能需要重新啟動伺服器，才能看到這些變更。
