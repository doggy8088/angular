# DI 中的循環依賴

<docs-video src="https://www.youtube.com/embed/CpLOm4o_FzM"/>

當服務的 [依賴](guide/di/hierarchical-dependency-injection) 直接或間接依賴服務本身時，就會產生循環依賴。例如，如果 `UserService` 依賴 `EmployeeService`，而 `EmployeeService` 也依賴 `UserService`。Angular 必須實例化 `EmployeeService` 以建立 `UserService`，而 `UserService` 本身依賴 `UserService`。

## 偵錯錯誤

使用呼叫堆疊來確定循環依賴存在的位置。
您可以透過[繪製](guide/di/di-in-action)組件、模組或服務的依賴關係，並識別導致問題的迴圈來查看是否有任何子依賴關係依賴原始檔案。

中斷此相依性的迴圈（或循環）以解決此錯誤。這通常表示移除或重構相依性，使其不相互依賴。
