# 選擇器衝突

<docs-video src="https://www.youtube.com/embed/z_3Z5mOm59I"/>

有兩個以上的[元件](guide/components)使用相同的元素選擇器。由於一個元素只能關聯到單一元件，選擇器必須是唯一的字串，Angular 才不會產生歧義。

## 如何除錯

使用錯誤訊息中的元素名稱，搜尋你的程式碼庫中使用了相同選擇器宣告的位置：

<docs-code language="typescript">

@Component({
  selector: 'YOUR_STRING',
  …
})

</docs-code>

請確保每個元件都有唯一的 CSS 選擇器。這樣才能保證 Angular 會渲染出你預期的元件。

如果你難以找出使用這個選擇器標籤名稱的多個元件，請檢查從匯入的元件庫（例如 Angular Material）來的元件。並請確保你的選擇器有遵循[最佳實務](style-guide#component-selectors)，以避免發生衝突。
