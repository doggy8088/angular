# 缺少參照目標

<docs-video src="https://www.youtube.com/embed/fUSAg4kp2WQ"/>

Angular 找不到匯出名稱為 `{{ PLACEHOLDER }}` 的指令。
這常是因為缺少匯入，或指令上缺少 [`exportAs`](api/core/Directive#exportAs)。

HELPFUL: 這是常見執行時期錯誤 [NG0301: Export Not Found](errors/NG0301) 的編譯器對應版本。

## 除錯方式

使用找不到的匯出的字串名稱，追蹤使用此匯出的範本或模組。

確保所有依賴都已正確匯入並在我們的模組中宣告。
例如，如果找不到的匯出是 `ngForm`，我們就需要在 `*.module.ts` 中匯入 `FormsModule` 並把它宣告在匯入清單中，以解決缺少匯出的錯誤。

<docs-code language="typescript">

import { FormsModule } from '@angular/forms';

@NgModule({
  …
  imports: [
    FormsModule,
    …

</docs-code>

如果你最近才加入某個匯入，你需要重新啟動伺服器才能看到這些變更。
