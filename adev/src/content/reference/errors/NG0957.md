# @for 使用的集合無法迭代

`@for` 迴圈會重複走訪陣列，或是走訪實作了 [iterable protocol](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Iteration_protocols) 的值，例如 `Map`、`Set` 或產生器。這個錯誤表示該集合兩者皆非，最常見的情況是傳入了一個純物件：

```angular-ts
@Component({
  template: `@for (item of items; track item) {
    {{ item }}
  }`,
})
class Test {
  items = {first: 'a', second: 'b'};
}
```

`null` 和 `undefined` 不會拋出錯誤，而是直接不渲染任何內容，因此這個錯誤只會在值確實存在、但無法迭代時回報。

## 修正方式

若要重複走訪純物件的項目，請使用 [KeyValue 管道](/api/common/KeyValuePipe)：

```angular-ts
@Component({
  imports: [KeyValuePipe],
  template: `@for (item of items | keyvalue; track item.key) {
    {{ item.key }}: {{ item.value }}
  }`,
})
class Test {
  items = {first: 'a', second: 'b'};
}
```

如果集合來自 API 呼叫或其他動態來源，請檢查該值本身是否就是清單。常見的原因是回應把清單包在另一個物件裡，例如 `{data: [...]}`。
