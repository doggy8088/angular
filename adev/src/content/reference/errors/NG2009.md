# 無效的 Shadow DOM 選擇器

使用 `ViewEncapsulation.ShadowDom` 的元件，其選擇器不符合自訂元素標籤名稱的要求。

標籤名稱要被視為有效的自訂元素名稱，必須：

- 全部小寫。
- 包含連字號。
- 以字母（a-z）開頭。

## 除錯方式

重新命名你的元件選擇器，讓它符合要求。

**修改前**：

```ts
@Component({
  selector: 'comp',
  encapsulation: ViewEncapsulation.ShadowDom
…
})

```

**修改後**：

```ts
@Component({
  selector: 'app-comp',
  encapsulation: ViewEncapsulation.ShadowDom
…
})
```
