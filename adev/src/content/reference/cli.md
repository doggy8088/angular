# CLI 參考文件

| 指令                               | 別名       | 說明                                                                                                      |
| :--------------------------------- | :--------- | :-------------------------------------------------------------------------------------------------------- |
| [`add`](cli/add)                   |            | 為你的專案加入外部函式庫的支援。                                                                          |
| [`analytics`](cli/analytics)       |            | 設定 Angular CLI 使用指標的收集。                                                                         |
| [`build`](cli/build)               | `b`        | 將 Angular 應用程式或函式庫編譯到指定輸出路徑下名為 dist/ 的輸出目錄。                                   |
| [`cache`](cli/cache)               |            | 設定持久磁碟快取並取得快取統計資訊。                                                                      |
| [`completion`](cli/completion)     |            | 為你的終端機設定 Angular CLI 自動完成。                                                                   |
| [`config`](cli/config)             |            | 取得或設定工作區中 angular.json 檔案的 Angular 設定值。                                                   |
| [`deploy`](cli/deploy)             |            | 為工作區中指定的專案或預設專案叫用部署建置器。                                                            |
| [`e2e`](cli/e2e)                   | `e`        | 建置並提供 Angular 應用程式，然後執行端對端測試。                                                         |
| [`extract-i18n`](cli/extract-i18n) |            | 從原始碼擷取 i18n 訊息。                                                                                  |
| [`generate`](cli/generate)         | `g`        | 根據原理圖產生和／或修改檔案。                                                                            |
| [`lint`](cli/lint)                 |            | 在指定專案資料夾中對 Angular 應用程式程式碼執行 lint 工具。                                               |
| [`new`](cli/new)                   | `n`        | 建立新的 Angular 工作區。                                                                                 |
| [`run`](cli/run)                   |            | 以專案中定義的可選自訂建置器設定，執行 Architect 目標。                                                   |
| [`serve`](cli/serve)               | `s`, `dev` | 建置並提供你的應用程式，並在檔案變更時重新建置。                                                          |
| [`test`](cli/test)                 | `t`        | 在專案中執行單元測試。                                                                                    |
| [`update`](cli/update)             |            | 更新你的工作區及其相依性。請參閱[更新指南](/update-guide)。                                               |
| [`version`](cli/version)           | `v`        | 輸出 Angular CLI 版本。                                                                                   |
