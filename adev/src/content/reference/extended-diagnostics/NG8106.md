# 不支援的後綴

這項診斷會偵測在屬性繫結中使用 `.px`、`.%` 與 `.em` 後綴的情況。


<docs-code language="html">

<img [attr.width.px]="5">

</docs-code>

## 這樣寫有什麼問題？

這些後綴只能用於樣式繫結。用在屬性繫結上時，它們不具有任何意義。

## 我應該怎麼做？

不要使用只能在樣式繫結中支援的 `.px`、`.%` 或 `.em` 後綴，改把單位寫進繫結的值裡。

<docs-code language="html">

<img [attr.width]="'5px'">

</docs-code>

## 設定需求

任何擴充診斷要發出訊息，都必須啟用 [`strictTemplates`](tools/cli/template-typecheck#strict-mode)。
`invalidBananaInBox` 除了 `strictTemplates` 之外，沒有其他額外需求。

## 如果無法避免，該怎麼辦？

可以透過編輯專案的 `tsconfig.json` 檔案來停用這項診斷：

<docs-code language="json">
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "suffixNotSupported": "suppress"
      }
    }
  }
}
</docs-code>

詳情請見[擴充診斷設定](extended-diagnostics#configuration)。
