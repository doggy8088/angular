# 未使用的獨立元件 imports

這項診斷會偵測 `@Component` 的 `imports` 陣列中，含有未在範本內使用的符號的情況。

<docs-code language="typescript">

@Component({
  imports: [UsedDirective, UnusedPipe]
})
class AwesomeCheckbox {}

</docs-code>

## 這樣寫有什麼問題？

未使用的 imports 會為程式碼增加不必要的雜訊，還可能拉長編譯時間。

## 我應該怎麼做？

刪除未使用的 import。

<docs-code language="typescript">

@Component({
  imports: [UsedDirective]
})
class AwesomeCheckbox {}

</docs-code>

## 如果無法避免，該怎麼辦？

可以透過編輯專案的 `tsconfig.json` 檔案來停用這項診斷：

<docs-code language="json">
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "unusedStandaloneImports": "suppress"
      }
    }
  }
}
</docs-code>

詳情請見[擴充診斷設定](extended-diagnostics#configuration)。
