# 缺少控制流指令

此診斷確保在範本中使用已知控制流程指令（例如 `*ngIf`、`*ngFor` 或 `*ngSwitch`）的獨立元件也會個別匯入這些指令，或透過匯入 `CommonModule` 匯入。

<docs-code language="typescript">

import {Component} from '@angular/core';

@Component({
  standalone: true,
  // Template uses `*ngIf`, but no corresponding directive imported.
  imports: [],
  template: `<div *ngIf="visible">Hi</div>`,
})
class MyComponent {}

</docs-code>

## 有什麼問題？

不匯入控制流程指令，就會在執行時期失敗，因為 Angular 會嘗試繫結到 HTML 元素的 `ngIf` 屬性，但該屬性不存在。

## 我該怎麼做？

請確定已匯入對應的控制流程指令。

指令可以單獨導入：

<docs-code language="typescript">

import {Component} from '@angular/core';
import {NgIf} from '@angular/common';

@Component({
  standalone: true,
  imports: [NgIf],
  template: `<div *ngIf="visible">Hi</div>`,
})
class MyComponent {}

</docs-code>

或你可以匯入整個 `CommonModule`，它包含所有控制流程指令：

<docs-code language="typescript">

import {Component} from '@angular/core';
import {CommonModule} from '@angular/common';

@Component({
  standalone: true,
  imports: [CommonModule],
  template: `<div *ngIf="visible">Hi</div>`,
})
class MyComponent {}

</docs-code>

## 組態需求

必須啟用 [`strictTemplates`](tools/cli/template-typecheck#strict-mode) 才能發出任何延伸診斷。
`missingControlFlowDirective` 沒有 `strictTemplates` 以外的其他額外需求。

## 如果我無法避免這件事怎麼辦？

這個診斷可以透過編輯專案的 `tsconfig.json` 檔案停用：

<docs-code language="json">
{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "missingControlFlowDirective": "suppress"
      }
    }
  }
}
</docs-code>

參閱 [進階診斷設定](extended-diagnostics#configuration) 以取得更多資訊。
