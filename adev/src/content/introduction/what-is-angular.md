<docs-decorative-header title="什麼是 Angular？" imgSrc="adev/src/assets/images/globe.svg" gradientBackground="true">
  Angular 是一個 Web 框架，讓開發者能建置快速、可靠又深受使用者喜愛的應用程式。
</docs-decorative-header>

<div style="margin: 2em">
  Angular 由 Google 一支專責團隊維護，提供一整套豐富的工具、API 與函式庫，簡化並加速你的開發流程。Angular 為你提供穩固的平台，讓你建置快速、可靠的應用程式，無論團隊人數或程式碼庫規模如何成長，都能從容因應。Angular.dev 是 Angular 官方文件的所在地。
</div>

<docs-card-container headerTitle="驅動你開發工作的功能" headerImgSrc="adev/src/assets/images/learn-angular-browser-bw.svg">
  <docs-card title="元件" href="essentials/components" link="開始使用元件" iconImgSrc="adev/src/assets/icons/components.svg">
    Angular 元件讓你輕鬆把程式碼拆分成封裝良好的小部分。
  </docs-card>
  <docs-card title="Angular Signals" href="essentials/signals" link="探索 Angular Signals" titleIconName="sensors" iconImgSrc="adev/src/assets/icons/signals.svg">
    我們細粒度的反應式模型，結合編譯時期的最佳化，簡化了開發工作，並預設就能建置出更快的應用程式。
  </docs-card>
  <docs-card title="伺服器端渲染" href="guide/ssr" link="了解 SSR" iconImgSrc="adev/src/assets/icons/ssr.svg">
    Angular 同時支援伺服器端渲染（SSR）與靜態網站產生（SSG），並提供完整的 DOM 水合（hydration）。
  </docs-card>
  <docs-card title="依賴注入" href="essentials/dependency-injection" link="探索依賴注入" iconImgSrc="adev/src/assets/icons/di.svg">
    輕鬆在整個應用程式的各個元件之間共享程式碼。
  </docs-card>
  <docs-card title="Angular 路由" href="guide/routing" link="探索 Angular 路由" iconImgSrc="adev/src/assets/icons/routing.svg">
    提供功能豐富的導覽工具組，包括路由守衛、資料解析、延遲載入等眾多功能的支援。
  </docs-card>
  <docs-card title="Angular 中的表單" href="guide/forms" link="探索表單" iconImgSrc="adev/src/assets/icons/forms.svg">
    提供一套標準化的系統，處理表單參與與驗證。
  </docs-card>
</docs-card-container>

<docs-card-container headerTitle="以前所未有的速度開發應用程式" headerImgSrc="adev/src/assets/images/browser-bolt.svg">
  <docs-card title="CLI" href="tools/cli" link="Angular CLI" iconImgSrc="adev/src/assets/icons/cli.svg">
    Angular CLI 讓你的專案在一分鐘內就能跑起來，並提供你所需的指令，一路成長為部署上線的正式應用程式。
  </docs-card>
  <docs-card title="DevTools" href="tools/devtools" link="Angular DevTools" iconImgSrc="adev/src/assets/icons/dev-tools.svg">
    Angular DevTools 與你瀏覽器的開發者工具並列運作，協助你除錯與分析應用程式，包括元件樹檢視器、依賴注入樹狀檢視，以及自訂的效能分析火焰圖。
  </docs-card>
  <docs-card title="ng update" href="update" link="ng update" iconImgSrc="adev/src/assets/icons/ng-update.svg">
    Angular CLI 的 `ng update` 會執行自動化的程式碼轉換，自動處理例行的破壞性變更，大幅簡化主要版本升級。保持在最新版本，能讓你的應用程式盡可能快速又安全。
  </docs-card>
  <docs-card title="Language Service" href="tools/language-service" link="Language Service" iconImgSrc="adev/src/assets/icons/language-service.svg">
    Angular 的 IDE 語言服務，為你喜愛的編輯器提供程式碼自動完成、導覽、重構與即時診斷功能。
  </docs-card>
</docs-card-container>

<docs-card-container headerTitle="安心交付" headerImgSrc="adev/src/assets/images/rocket.svg">
  <docs-card title="每一筆提交都對照 Google 龐大的單一程式碼庫驗證" href="https://cacm.acm.org/research/why-google-stores-billions-of-lines-of-code-in-a-single-repository/" link="了解 Google 的單一程式碼庫" titleIconName="sensors">
    <p>Angular 的每一筆提交，都會對照 Google 內部程式碼庫中數十萬個測試進行檢查，涵蓋無數真實世界的使用情境。</p>
    <p>Angular 致力於為 Google 一些最大的產品（包括 Google Cloud）提供穩定性。這份承諾確保每項變更都經過充分測試、保持向後相容，並在可能的情況下附帶遷移工具。</p>
  </docs-card>
  <docs-card title="明確的支援政策與可預期的發佈時程" href="reference/releases" link="版本管理與發佈" titleIconName="sensors">
    Angular 以時間為基準、可預期的發佈時程，讓你的組織對框架的穩定性與向後相容性充滿信心。長期支援（LTS）期間確保你在需要時能取得關鍵的安全性修正。第一方的更新工具、指南與自動化遷移原理圖，協助你的應用程式跟上框架與 Web 平台的最新進展。
  </docs-card>
</docs-card-container>

<docs-card-container headerTitle="適用於任何規模" headerImgSrc="adev/src/assets/images/servers.svg">
  <docs-card title="以國際化支援觸及世界各地的使用者" href="guide/i18n" link="國際化" titleIconName="sensors">
    Angular 的國際化功能處理訊息翻譯與格式化，包括對 Unicode 標準 ICU 語法的支援。
  </docs-card>
  <docs-card title="預設安全，保護你的使用者" href="best-practices/security" link="安全性" titleIconName="sensors">
    Angular 與 Google 世界級的安全工程師合作，致力於讓開發預設就安全。內建的安全功能，包括 HTML 清理與 trusted type 支援，協助保護你的使用者免於跨網站指令碼與跨網站請求偽造等常見弱點的威脅。
  </docs-card>
  <docs-card title="以 Vite 與 esbuild 讓大型團隊保持高生產力" href="tools/cli/build-system-migration" link="Vite and esbuild" titleIconName="sensors">
    Angular CLI 內含使用 Vite 與 esbuild 的快速現代化建置管線。據開發者回報，擁有數十萬行程式碼的專案，也能在一分鐘內完成建置。
  </docs-card>
  <docs-card title="已在 Google 一些最大的 Web 應用程式中實證" titleIconName="sensors">
    Google 的大型產品建立在 Angular 的架構之上，並協助開發新功能，進一步提升 Angular 的可擴展性，從 [Google Fonts](https://fonts.google.com/) 到 [Google Cloud](https://console.cloud.google.com) 都是如此。
  </docs-card>
</docs-card-container>
