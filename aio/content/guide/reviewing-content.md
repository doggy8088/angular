# 檢閱內容

當 Angular 開發者能取得正確且完整的文件時，他們的工作表現最好。
讓現有內容保持最新，是確保所有開發者都有良好文件體驗的重要一環。

本主題說明如何透過檢閱內容，協助讓 Angular 內容保持最新狀態。

## 開始之前

即使你從未為 Angular 做出過貢獻，你也可以檢閱內容。
不過，如果你要在儲存庫中提交你的第一個提取請求，手邊有[為 Angular 做出貢獻](https://github.com/angular/angular/blob/main/CONTRIBUTING.md)指南可能會有所幫助。

## 檢閱內容（`@reviewed`）

你在 Angular.io 上看到的所有任務型指南、教學與概念主題都支援 `@reviewed` 標籤。
當這個標籤存在時，其後會跟著一個日期，代表該主題被檢閱其正確性與完整性的時間。
在已發布的主題上，這項檢閱資訊會出現在主題底部；例如，`Last reviewed on` 後面接著星期、月份、日與年份。

這個檢閱日期表示某人上次檢閱該主題，以確保其內容正確的時間。

你可以使用 GitHub 使用者介面，或在本機的編輯器中檢閱主題。
你也可以檢閱任何你喜歡的主題。
對該主題領域的先前經驗會有所幫助，但並非必要。

**檢閱主題的步驟：**

1.  導覽至你想檢閱的主題。
1.  找到主題底部的上次檢閱日期，並確認該主題符合[檢閱標準](#review-criteria)。

    如果主題沒有上次檢閱日期，歡迎你把它加入主題。
    加入日期時，請使用 `YYYY-MM-DD` 日期格式。
    範例：
    `@reviewed 2021-03-23`

1.  通讀該主題。
1.  如果主題需要更新，請[提交議題](https://github.com/angular/angular/blob/main/CONTRIBUTING.md#submit-issue)說明所需的更新，或[建立提取請求](https://github.com/angular/angular/blob/main/CONTRIBUTING.md#submit-pr)附上更新。
1.  透過 [GitHub 使用者介面](guide/updating-content-github-ui) 或 Angular 的[標準提取請求流程](https://github.com/angular/angular/blob/main/CONTRIBUTING.md#submit-pr)，更新 `@reviewed` 標籤。

<a id="review-criteria"></a>

### 檢閱標準

一般來說，主題應該每六個月檢閱一次，或在每個主要版本發布前後檢閱。
