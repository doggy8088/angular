# 選擇文件議題

本主題說明如何選擇要修正的 Angular 文件議題。

Angular 文件議題儲存在 [angular/angular](https://github.com/angular/angular) 儲存庫的 **Issues** 分頁中。文件議題可透過 `comp: docs` 標籤識別，並依優先順序標記。

歡迎你處理他人尚未著手的[任何議題](#links-to-documentation-issues)。如果你知道文件中尚未回報的問題，也可以[建立新的文件議題](https://github.com/angular/angular/issues/new?assignees=&labels=&template=3-docs-bug.yaml)。

選擇要修正的議題時，可以考慮以下幾點：

*   修正優先順序較高的議題對社群更有價值。
*   如果你是開放原始碼軟體的新手，優先順序較低的議題或 `good first issue` 會是很好的起點。
*   每一項貢獻都有助於改善文件。

選擇要解決的議題後：

1.  在議題頁面中，加入 `working on fix` 作為註解，讓他人知道你正在處理它。
1.  繼續閱讀[開始編輯文件主題](guide/doc-update-start)。
