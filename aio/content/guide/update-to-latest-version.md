# 更新 Angular

本指南包含更新到 Angular 第 14 版的資訊。

## 更新 Angular CLI 應用程式

如需逐步了解如何更新到最新的 Angular 版本、並運用 Angular 自動遷移工具，請使用 [update.angular.io](https://update.angular.io) 上的互動式更新指南。

## 第 14 版的變更與棄用

<div class="alert is-helpful">

關於 Angular 的棄用與移除實務，請參閱 [Angular 發行實務](guide/releases#淘汰實務)。

</div>

*   **嚴格型別的反應式表單**

    反應式表單的 `AbstractControl`、`FormControl`、`FormGroup` 與 `FormArray` 型別現在支援泛型參數，可對控制項進行嚴格型別檢查。自動遷移會把這些型別現有的用法轉換為特殊的 `Untyped` 別名，以保留現有的行為。

    `initialValueIsDefault` 選項在建構 `FormControl` 時已被棄用，改用 `nonNullable` 選項（兩者行為相同）。這次更名讓 `FormControl` 建構子與其他和可空性相關的嚴格型別 API 保持一致。

*   **`ComponentFactory` 與 `NgModuleFactory` 清理**

    許多使用 `ComponentFactory` 或 `NgModuleFactory` 的 API 已經棄用，並由直接使用元件或 NgModule 類別的新 API 取代。

### Angular 第 14 版中的破壞性變更

<a id="breaking-changes"></a>

|                                                                     | 詳細資訊                                                                                                                                                                                                                                                                                                                                                            |
|:--- |:--- |
| [**PR&nbsp;#45729**](https://github.com/angular/angular/pull/45729) | `initialNavigation: 'enabled'` 已在 v11 棄用，改由 `initialNavigation: 'enabledBlocking'.` 取代。                                                                                                                                                                                                                                                   |
| [**PR&nbsp;#42803**](https://github.com/angular/angular/pull/42803) | 表單 `email` 輸入強制轉型：表單 `email` 輸入值只要以任何值定義，就會被視為 true，而非 false 與 'false'。                                                                                                                                                                                                                  |
| [**PR&nbsp;#33729**](https://github.com/angular/angular/pull/33729) | 長度鍵設為零的物件將不再驗證為空值。嚴格來說這是破壞性變更，因為鍵為 `length`、值為 `0` 的物件將不再驗證為空值。這是非常小的變更，任何依賴此行為的程式大概本來就有錯誤。                                                                          |
| [**PR&nbsp;#44921**](https://github.com/angular/angular/pull/44921) | 載入 Hammer 時不再執行變更偵測。這項變更可能導致那些隱含斷言變更偵測特定次數或順序的單元測試失敗。                                                                                                                                                                               |
| [**PR&nbsp;#23020**](https://github.com/angular/angular/pull/23020) | `TransferState` 用法的參數型別提高了型別安全性，這可能會揭露現有有問題的呼叫。                                                                                                                                                                                                                                               |
| [**PR&nbsp;#43863**](https://github.com/angular/angular/pull/43863) | `Navigation#initialUrl` 的型別已收窄為 `UrlTree`，以反映實際情況。此外，`initialUrl` 的值現在符合其文件說明：「在導覽前傳入 Router#navigateByUrl() 呼叫的目標 URL」。先前它被錯誤地設為導覽發生時 Router 目前內部的 `UrlTree`。 |
| [**PR&nbsp;#45114**](https://github.com/angular/angular/pull/45114) | `AnimationDriver.getParentElement` 方法已成為必要方法，因此這個介面的任何實作者現在都必須為這個方法提供實作。                                                                                                                                                                                            |
| [**PR&nbsp;#45176**](https://github.com/angular/angular/pull/45176) | `Route.pathMatch` 的型別現在更為嚴格。使用 `pathMatch` 的地方可能需要更新，明確標註 `Route`／`Routes` 型別，以免 TypeScript 將型別推斷為 `string`。                                                                                                                                                     |
| [**PR&nbsp;#44573**](https://github.com/angular/angular/pull/44573) | 路由器現在只取解析器發出的第一個值，然後繼續導覽。這現在與其他守衛回傳的 `Observables` 一致：只使用第一個值。                                                                                                                                                            |
| [**PR&nbsp;#45394**](https://github.com/angular/angular/pull/45394) | 不再支援 `4.6.0` 之前的 TypeScript 版本。                                                                                                                                                                                                                                                                                                    |
| [**PR&nbsp;#45210**](https://github.com/angular/angular/pull/45210) | `HttpClient` 在 JSONP 請求設定標頭時會擲出錯誤。                                                                                                                                                                                                                                                                                          |
| [**PR&nbsp;#43834**](https://github.com/angular/angular/pull/43834) | 反應式表單型別（例如 `FormControl` 與 `FormGroup`）現在具有泛型型別參數，並推斷出更嚴格的型別。遷移會把現有用法轉換為新的 `Untyped` 前綴別名，以保留現有的行為。                                                                                                                              |
| [**PR&nbsp;#45487**](https://github.com/angular/angular/pull/45487) | 已移除 `TestBed` 設定中已棄用的 `aotSummaries` 欄位。                                                                                                                                                                                                                                                                               |
| [**PR&nbsp;#45648**](https://github.com/angular/angular/pull/45648) | 新增了必要的類別成員 `LocationStrategy#getState`，這個介面的任何實作者都需要提供它。                                                                                                                                                                                                                              |
| [**PR&nbsp;#45735**](https://github.com/angular/angular/pull/45735) | 當守衛回傳 `UrlTree` 時，路由器先前會在 `setTimeout` 內排程重新導向導覽。這個逾時現在已移除，可能會因測試寫法不正確而導致測試失敗。                                                                                                                                             |
