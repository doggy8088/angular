# 選用的國際化實務

以下選用主題可協助你手動設定應用程式的國際化設定。
這些選用實務是為進階或自訂的 Angular 應用程式而設計的。

## 先備知識

為了讓你的專案做好翻譯準備，你應該對下列主題有基本了解。

*   [範本][AioGuideGlossaryTemplate]
*   [元件][AioGuideGlossaryComponent]
*   用於管理 Angular 開發週期的 [Angular CLI][AioCliMain] [命令列][AioGuideGlossaryCommandLineInterfaceCli]工具
*   翻譯檔案使用的[可延伸標記語言 (XML)][W3Xml]
