@name 選擇器衝突
@category runtime
@videoUrl https://www.youtube.com/embed/z_3Z5mOm59I
@shortDescription 多個元件使用相同的標籤名稱

@description
兩個以上的元件使用相同的[元素選擇器](guide/component-overview#指定元件的-css-選擇器)。由於一個元素只能對應一個元件，選擇器必須是唯一的字串，以免 Angular 產生歧義。

@debugging
使用錯誤訊息中的元素名稱，搜尋你的程式碼庫中使用了相同[選擇器宣告](guide/architecture-components)的位置：

```typescript
@Component({
  selector: 'YOUR_STRING',
  ...
})
```

請確保每個元件都有唯一的 CSS 選擇器。這樣才能保證 Angular 會渲染出你預期的元件。

如果你難以找出使用這個選擇器標籤名稱的多個元件，請檢查從匯入的元件庫（例如 Angular Material）來的元件。並請確保你的選擇器有遵循[最佳實務](guide/styleguide#元件選擇器)，以避免發生衝突。
