@name 無效的 multi provider
@category runtime
@shortDescription 預期 provider 為 `multi: true`，但未取得陣列

@description

當 Angular 注入一個預期要搭配 `multi: true` 使用的權杖，卻發現它的值不是陣列時，Angular 執行階段就會拋出這個錯誤。例如，`ENVIRONMENT_INITIALIZER` 應該像 `{provide: ENVIRONMENT_INITIALIZER, multi: true, useValue: () => {...}}` 這樣提供。
