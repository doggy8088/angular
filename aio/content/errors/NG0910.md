@name iframe 元素上的不安全繫結
@category runtime
@shortDescription iframe 元素上的不安全繫結

@description
當 Angular 偵測到 `<iframe>` 元素上使用了下列特性名稱的屬性繫結或特性繫結時，你會看到此錯誤：

* sandbox
* allow
* allowFullscreen
* referrerPolicy
* csp
* fetchPriority

上述屬性會影響 `<iframe>` 的安全性模型設定，因此必須在設定 `src` 或 `srcdoc` 屬性之前套用。為確保這一點，Angular 要求這些屬性在 `<iframe>` 上設定為靜態屬性，讓它們的值在元素建立時就設定好，並在該 `<iframe>` 實例的整個生命週期中保持不變。

使用帶有上述任一特性名稱的屬性繫結時，會拋出此錯誤：
```html
<iframe [sandbox]="'allow-scripts'" src="..."></iframe>
```

或是使用特性繫結時：

```html
<iframe [attr.sandbox]="'allow-scripts'" src="..."></iframe>
```

另外，在指令的宿主繫結中使用類似模式時，也會拋出此錯誤：

```typescript
@Directive({
  selector: 'iframe',
  host: {
    '[sandbox]': `'allow-scripts'`,
    '[attr.sandbox]': `'allow-scripts'`,
  }
})
class IframeDirective {}
```

@debugging

錯誤訊息包含含有不安全繫結之 `<iframe>` 元素的範本所在的元件名稱。

建議的解法是把上述屬性用作靜態屬性，例如：

```html
<iframe sandbox="allow-scripts" src="..."></iframe>
```

如果你需要讓這些屬性有不同的值（依各種條件而定），你可以在 `<iframe>` 元素上使用 `*ngIf` 或 `*ngSwitch`：

```html
<iframe *ngIf="someConditionA" sandbox="allow-scripts" src="..."></iframe>
<iframe *ngIf="someConditionB" sandbox="allow-forms" src="..."></iframe>
<iframe *ngIf="someConditionC" sandbox="allow-popups" src="..."></iframe>
```
