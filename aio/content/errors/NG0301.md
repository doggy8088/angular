@shortDescription 找不到 export！

@description
Angular 找不到 export 名稱為 `{{ PLACEHOLDER }}` 的指令。export 名稱是在指令裝飾器的 `exportAs` 屬性中指定的。這種情況常見於在範本中使用 FormsModule 或 Material 模組，卻忘了[匯入對應的模組](guide/sharing-ngmodules)。

<div class="alert is-helpful">

這是常見的編譯器錯誤 [NG8003：找不到具有 export 的指令](errors/NG8003) 在執行階段的對應錯誤。

</div>

@debugging
使用 export 名稱，追蹤使用這個 export 的範本或模組。

請確保所有依賴都已[正確匯入並宣告在你的 NgModule 中](guide/sharing-ngmodules)。例如，找不到的 export 若是 `ngForm`，我們就必須匯入 `FormsModule`，並在 `*.module.ts` 的 imports 清單中宣告它，才能解決這個錯誤。

```typescript
import { FormsModule } from '@angular/forms';

@NgModule({
  ...
  imports: [
    FormsModule,
    …
```

如果你最近才加入新的匯入，可能需要重新啟動伺服器，才能看到這些變更。
