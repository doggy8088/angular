功能與優勢

跨平台
漸進式 Web 應用程式

運用現代 Web 平台功能，帶來如應用程式般的體驗。 高效能、可離線使用、零步驟安裝。

原生應用程式

運用 Cordova、Ionic 或 NativeScript 的策略，建置原生行動應用程式。

桌面應用程式

使用你為 Web 學會的相同 Angular 方法，在 Mac、Windows 與 Linux 上建立可安裝於桌面的應用程式，還能存取原生作業系統 API。

速度與效能
程式碼產生

Angular 將你的範本轉換成針對當今 JavaScript 虛擬機器高度最佳化的程式碼，讓你兼得手寫程式碼的全部好處與框架的生產力。

Universal

在 Node.js®、.NET、PHP 與其他伺服器上提供應用程式的第一個檢視，僅用 HTML 與 CSS 就能近乎即時地算繪。也為針對 SEO 最佳化的網站鋪路。

程式碼分割

Angular 應用程式藉由全新的元件路由器快速載入，它提供自動程式碼分割，讓使用者只載入算繪所請求檢視所需的程式碼。

生產力
範本

使用簡單而強大的範本語法，快速建立 UI 檢視。

Angular CLI

命令列工具：快速開始建置、加入元件與測試，然後立即部署。

IDE

在熱門的編輯器與 IDE 中，獲得智慧型程式碼自動完成、即時錯誤提示與其他回饋。

完整的開發流程
測試

透過 Karma 進行單元測試，每次儲存時你都能知道自己是否弄壞了什麼。

動畫

透過 Angular 直覺的 API，只用極少的程式碼就能建立高效能、複雜的編排與動畫時間軸。

無障礙

使用支援 ARIA 的元件、開發者指南與內建的無障礙（a11y）測試基礎設施，建立無障礙應用程式。
