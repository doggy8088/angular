品牌名稱

Angular

名稱 Angular 代表 Angular 團隊為你提供的成果與承諾。

若未特別指明，Angular 指的就是 Angular 團隊最新、最棒的穩定版本。

範例

v4.1 版現已推出 - 我們很高興宣布，最新版的 Angular 現已推出。保持最新狀態就是這麼簡單！

範例

正確： "New *ngIf capabilities—new in version 4.0 is the ability to ..."

不正確： "New *ngIf capabilities in Angular 4—Angular 4 introduces the ability to ..."

理由

不在標題中使用「Angular 4」，內容在第 5、6、7 版推出後仍然適用且有用，因為語法在短期與中期的未來不太可能改變。

AngularJS

AngularJS 是 Angular 團隊提供的 v1.x 系列成果與承諾。

範例

  • AngularJS 是當今網路上最常使用的框架之一（以專案數量計）。
  • 數百萬名開發者目前正在使用 AngularJS 開發。
  • 開發者開始從 AngularJS 升級到 Angular。
  • 我正在把我的應用程式從 AngularJS 升級到 Angular。
  • 我在這個專案中使用 AngularJS Material。

AngularJS 專案應使用 原始 AngularJS 標誌／ 圖示，而非 Angular 圖示：

Angular Material

這是 Angular 團隊為 Angular 應用程式提供 Material Design 元件所進行的工作。

AngularJS Material

這是 Angular 團隊針對與 AngularJS 相容的 Material Design 元件所進行的工作。

第三方專案

X for Angular

第三方在軟體專案中應使用「X for Angular」或「ng-X」這類術語。專案應避免使用 Angular X（例如 Angular UI Toolkit），因為這可能會造成作者身分的混淆。這條規則不適用於活動或聚會團體。

開發者應避免在專案名稱中使用 Angular 版本號碼，因為這會把專案人為地綁定在 Angular 的某個時間點，限制了專案的發展，或是日後需要改名。

若使用代號或簡稱，例如在 npm 或 GitHub 上，有些可以接受，有些則不行。

請勿使用
  • ng2-
  • angular2-
可以使用
  • ng-
  • angular-

一如往常，元件與指令的選取器不應以「ng-」開頭，否則會與 Angular 團隊提供的元件和指令衝突。

範例

  • ng-BE 團隊剛推出 ng-health，協助開發者追蹤自己的健康狀況。
  • 我打算使用 NativeScript for Angular，來運用原生 UI 元件。
  • ReallyCoolTool for Angular。
  • ReallyCoolTool for AngularJS。
