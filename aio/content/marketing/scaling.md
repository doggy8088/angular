# 擴展 Angular 應用程式

Angular 適用於任何規模的應用程式，Angular 工具也能在應用程式成長的過程中提供支援。

## Angular 如何協助你擴展應用程式

以下是一些支援擴展 Angular 應用程式的 Angular 功能。

### TypeScript 支援

Angular 應用程式以 [TypeScript][typescript-home] 撰寫。TypeScript 為 JavaScript 加上語法以提供強型別檢查。你的整合式開發環境（IDE）可以套用靜態型別檢查來[協助你更早發現錯誤][type-checking-doc]，並在你日後重構時提供協助。

TypeScript 的強型別檢查為你的應用程式打下穩固的基礎，讓你能放心地持續成長。

### 強大的命令列介面

Angular CLI 提供了強大的[命令列介面][ng-command-list]，可執行常見的 Angular 應用程式開發工作。Angular CLI 遵循 Angular 風格指南，以支援元件之間的一致性。[`ng generate`][ng-generate] 命令與 [Angular 原理圖][schematic-overview] 能讓你應用程式的原始碼保持一致且井然有序，同時產生樣板程式碼，協助你開始建立應用程式。

### 元件程式庫

Angular 團隊維護[元件開發套件][material-cdk]與 [Material Design 元件][material-home]，Google 內部有數千個應用程式使用它們。在這樣的規模下使用，可確保各版本與整合的穩定性。

Angular 社群還維護了數十個其他的元件程式庫，讓你可以讓應用程式符合你的品牌。

### 內建表單與路由支援

Angular 內建對[表單][forms-overview]與[路由][routes-overview]的支援。這些功能每天都在 Google 內部的數千個應用程式中證明了自己的價值。

你的應用程式也可以放心地使用這些功能。
