# 人人適用的 Angular 應用程式

Angular 能協助你為每個人打造應用程式。Angular 包含支援無障礙設計的原生框架與工具擴充功能。Angular 內建的國際化支援，能協助你以不同語言觸及使用者。

## 無障礙設計（a11y）

不同能力的族群都會使用網頁應用程式。你的部分使用者可能會使用輔助技術來協助他們使用你的應用程式。Angular 支援無障礙設計，以及這些技術用來讓你的應用程式可供他們使用的屬性。

將應用程式設計得更無障礙，通常也能改善所有使用者的使用體驗。

[進一步了解 Angular 的無障礙設計][angular-accy]

## 國際化（i18n）與在地化（l10n）

Angular 的語法支援將你的應用程式在地化，其國際化工具則透過以下方式，讓你的應用程式更容易在地化：

*  擷取標記的文字，以便翻譯成不同語言
*  支援 Unicode 國際元件（ICU）運算式，以處理性別與複數等複雜的翻譯情況
*  支援多種翻譯
*  支援資料的地區設定專屬顯示格式

在我們的[說明文件][internationalization-doc]中進一步了解 Angular 的國際化工具，其中包含一段簡短的影片。
