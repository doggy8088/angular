學會一種用 Angular 建置應用程式的方法，重複使用你的程式碼與能力，為任何部署目標建置應用程式。無論是 Web、行動 Web、原生行動裝置還是原生桌面。

速度與效能

在今日的 Web 平台上達成可能的最快速度，並透過 Web Worker 與伺服器端算繪更進一步。

Angular 讓你掌控擴展性。在 RxJS、Immutable.js 或其他推播模型上建置資料模型，滿足龐大的資料需求。

強大的工具

使用簡單、宣告式的範本快速建置功能。用你自己的元件擴展範本語言，並運用各式各樣現有的元件。在幾乎每個 IDE 與編輯器中，獲得即時的 Angular 專屬協助與回饋。這一切結合起來，讓你能專注於建置出色的應用程式，而不是費心讓程式碼跑起來。
