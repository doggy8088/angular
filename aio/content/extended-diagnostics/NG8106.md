@name 不支援的後綴

@description

這項診斷會偵測 `.px`、`.%` 與 `.em` 後綴搭配 attribute 繫結使用的情形。這些後綴僅適用於樣式繫結。

<code-example format="html" language="html">

&lt;div [attr.width.px]="5"&gt;&lt;/div&gt;

</code-example>

## 我應該怎麼做？

不要使用只能在樣式繫結中支援的 `.px`、`.%` 或 `.em` 後綴，改把單位寫進繫結的值裡。

<code-example format="html" language="html">
  
&lt;div [attr.width]="'5px'"&gt;&lt;/div&gt;

</code-example>

## 如果無法避免，該怎麼辦？

可以透過編輯專案的 `tsconfig.json` 檔案來停用這項診斷：

<code-example format="json" language="json">

{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "suffixNotSupported": "suppress"
      }
    }
  }
}

</code-example>

詳情請見[擴充診斷設定](extended-diagnostics#設定)。
