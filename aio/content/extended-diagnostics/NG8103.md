@name 缺少控制流程指令

@description

這項診斷會確保：在範本中使用已知控制流程指令（例如 `*ngIf`、`*ngFor` 或 `*ngSwitch`）的獨立元件，也確實匯入了這些指令，無論是逐一匯入，還是透過匯入 `CommonModule` 來取得。

<code-example format="typescript" language="typescript">

import {Component} from '&commat;angular/core';

&commat;Component({
  standalone: true,
  // Template uses `*ngIf`, but no corresponding directive imported.
  template: `&lt;div *ngIf="visible"&gt;Hi&lt;/div&gt;`,
  // &hellip;
})
class MyComponent {}

</code-example>

## 如何修正這個問題

請確認有匯入對應的控制流程指令。

指令可以逐一匯入：

<code-example format="typescript" language="typescript">

import {Component} from '&commat;angular/core';
import {NgIf} from '&commat;angular/common';

&commat;Component({
  standalone: true,
  imports: [NgIf],
  template: `&lt;div *ngIf="visible"&gt;Hi&lt;/div&gt;`,
  // &hellip;
})
class MyComponent {}

</code-example>

或者也可以匯入完整的 `CommonModule`，它包含所有控制流程指令：

<code-example format="typescript" language="typescript">

import {Component} from '&commat;angular/core';
import {CommonModule} from '&commat;angular/common';

&commat;Component({
  standalone: true,
  imports: [CommonModule],
  template: `&lt;div *ngIf="visible"&gt;Hi&lt;/div&gt;`,
  // &hellip;
})
class MyComponent {}

</code-example>
