@name 對不可為 null 的值使用空值合併運算子

@description

這項診斷會偵測 Angular 範本中無用的空值合併運算子（`??`）。 具體來說，它會找出輸入值並非「可為 null」型別的運算，也就是其型別不包含 `null` 或 `undefined` 的情況。 對於這類值，`??` 右側的內容永遠不會被用到。

<code-example format="typescript" language="typescript">

import {Component} from '&commat;angular/core';

&commat;Component({
  // Template displays &grave;foo&grave; if present, falls back to 'bar' if it is &grave;null&grave;
  // or &grave;undefined&grave;.
  template: &grave;
    &lt;div&gt;
      {{ foo ?? 'bar' }}
    &lt;/div&gt;
  &grave;,
  // &hellip;
})
class MyComponent {
  // &grave;foo&grave; is declared as a &grave;string&grave; which *cannot* be &grave;null&grave; or &grave;undefined&grave;.
  foo: string = 'test';
}

</code-example>

## 這樣寫有什麼問題？

對不可為 null 的輸入值使用空值合併運算子不會有任何效果，而且代表值的允許型別與它在範本中的呈現方式之間存在落差。 開發者可能會合理地假設，空值合併運算子的右側在某些情況下會被顯示出來，但實際上它永遠不會顯示。 這可能會讓人對程式預期的輸出感到困惑。

## 我應該怎麼做？

讓範本與宣告的型別保持一致。 仔細檢查輸入值的型別，確認它是否真的預期可以為 null。

如果輸入值應該可以為 null，就把 `null` 或 `undefined` 加入它的型別來表明這一點。

<code-example format="typescript" language="typescript">

import {Component} from '&commat;angular/core';

&commat;Component({
  template: &grave;
    &lt;div&gt;
      {{ foo ?? 'bar' }}
    &ltl/div&gt;
  &grave;,
  // &hellip;
})
class MyComponent {
  // &grave;foo&grave; is now nullable. If it is ever set to &grave;null&grave;, 'bar' will be displayed.
  foo: string &verbar; null = 'test';
}

</code-example>

如果輸入值*不*應該可以為 null，就刪除 `??` 運算子及其右側運算元，因為 TypeScript 保證該值永遠不會是 null。

<code-example format="typescript" language="typescript">

import {Component} from '&commat;angular/core';

&commat;Component({
  // Template always displays &grave;foo&grave;, which is guaranteed to never be &grave;null&grave; or
  // &grave;undefined&grave;.
  template: &grave;
    &lt;div&gt;
      {{ foo }}
    &lt;/div&gt;
  &grave;,
  // &hellip;
})
class MyComponent {
  foo: string = 'test';
}

</code-example>

## 設定需求

任何擴充診斷要發出訊息，都必須啟用 [`strictTemplates`](guide/template-typecheck#嚴格模式)。 要發出 `nullishCoalescingNotNullable` 診斷，還必須啟用 [`strictNullChecks`](guide/template-typecheck#嚴格的-null-檢查)。

## 如果無法避免，該怎麼辦？

可以透過編輯專案的 `tsconfig.json` 檔案來停用這項診斷：

<code-example format="json" language="json">

{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "nullishCoalescingNotNullable": "suppress"
      }
    }
  }
}

</code-example>

詳情請見[擴充診斷設定](extended-diagnostics#設定)。
