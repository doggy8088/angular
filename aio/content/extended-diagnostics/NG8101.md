@name 不正確的 Banana-in-Box 語法

@description

這項診斷會偵測寫反的「banana-in-box」語法，也就是[雙向繫結](guide/two-way-binding)的錯誤寫法。

<code-example format="html" language="html">

&lt;div ([var])="otherVar"&gt;&lt;/div&gt;

</code-example>

## 這樣寫有什麼問題？

以目前的寫法來看，`([var])` 實際上是一個名稱為 `[var]` 的[事件繫結](guide/event-binding)。 作者很可能原本想寫的是對名為 `var` 的變數做雙向繫結，但照這樣寫，這個繫結不會有任何效果。

## 我應該怎麼做？

修正這個打字錯誤。 顧名思義，香蕉 `(` 應該放在盒子 `[]` 的*裡面*。 在本例中應寫成：

<code-example format="html" language="html">

&lt;div [(var)]="otherVar"&gt;&lt;/div&gt;

</code-example>

## 設定需求

任何擴充診斷要發出訊息，都必須啟用 [`strictTemplates`](guide/template-typecheck#嚴格模式)。 `invalidBananaInBox` 除了 `strictTemplates` 之外，沒有其他額外需求。

## 如果無法避免，該怎麼辦？

可以透過編輯專案的 `tsconfig.json` 檔案來停用這項診斷：

<code-example format="json" language="json">

{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "invalidBananaInBox": "suppress"
      }
    }
  }
}

</code-example>

詳情請見[擴充診斷設定](extended-diagnostics#設定)。
