@name 文字屬性未被視為繫結

@description

這項診斷會確保帶有 Angular 特殊繫結前綴（`attr.`、`style.` 與 `class.`）的屬性被解讀為繫結。舉例來說，`<div attr.id="my-id"></div>` 不會被解讀為對 `id` 的屬性繫結，而只是一般的屬性，並會原樣出現在最終的 HTML（`<div attr.id="my-id"></div>`）中。這很可能不是開發者的本意。開發者真正想做的，應該是把 `id` 設為 'my-id'（`<div id="my-id"></div>`）。

## 我應該怎麼做？

繫結到 `attr.`、`class.` 或 `style.` 時，請確認使用 Angular 範本繫結語法（`[]`）。

<pre>
  &lt;div [attr.id]="my-id">&lt;/div>
  &lt;div [style.color]="red">&lt;/div>
  &lt;div [class.blue]="true">&lt;/div>
</pre>


## 如果無法避免，該怎麼辦？

可以透過編輯專案的 `tsconfig.json` 檔案來停用這項診斷：

<code-example format="json" language="json">

{
  "angularCompilerOptions": {
    "extendedDiagnostics": {
      "checks": {
        "textAttributeNotBinding": "suppress"
      }
    }
  }
}

</code-example>

詳情請見[擴充診斷設定](extended-diagnostics#設定)。
